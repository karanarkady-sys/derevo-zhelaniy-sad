# Дерево Желаний — прототип «Сада»

Кликабельный прототип игрового режима «Сад»: три в ряд наполняет дерево светом, почка раскрывается и выдаёт мудрость с заданием и ответом Союзника. После трёх мудростей сад остаётся открыт для свободной игры за Искру.

Это прототип для обсуждения, а не часть приложения: ответы Союзника заготовлены заранее, числа баланса условные.

## Как открыть

Откройте `index.html` в браузере. Чтобы получить ссылку для показа, включите GitHub Pages: Settings → Pages → ветка `main`, папка `/ (root)`.

## Как играть

Меняйте местами две соседние клетки тапом по обеим или свайпом. Солнца дают дереву больше всего света, капли и листья понемногу, искры приносят ⊙. На 100% света открывается мудрость.
